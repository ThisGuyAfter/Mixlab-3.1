FL Studio stock toolkit / quick map

Fruity Parametric EQ 2

Corrective and tonal EQ. Use bands to find and shape frequency problems. Keep cuts/boosts purposeful.

Fruity Limiter

Limiter, compressor and gate functions. Also useful for sidechain ducking when routed correctly.

Maximus

Multiband dynamics, de-essing-style control and mastering-oriented dynamics. Powerful, so use modestly.

Peak control and distortion. Great for deliberate drum/bass color; level-match and monitor artifacts.

Fruity Delay 3 / Reeverb 2 / Convolver

Time-based effects. Prefer sends for shared spaces, filtered returns and automation.

ROUTING STUDIO

Signal flow beyond individual inserts: buses, sends, parallel paths and sidechains.

01 / Standard insert chain

One signal passes through processors in sequence. Each stage changes what the next stage receives.

SOURCE→CLEANUP→DYNAMICS→TONE→OUTPUT

Use for: corrective EQ, compression, saturation and final tone shaping.

02 / Send reverb or delay

Keep the dry source on its insert and send a controlled amount to a shared effect return.

DRY TRACK↘SEND→100% WET FX→RETURN

Use for: shared rooms, plates, tempo delays and filtered ambience.

03 / Parallel compression

Blend the original with a heavily compressed duplicate. The dry path preserves transients; the return adds sustain and density.

SOURCE↗DRY+COMPRESSED SEND

Use for: drums, vocals and bass when the main signal should remain dynamic.

04 / Sidechain ducking

A trigger signal controls gain reduction or volume on another track. The trigger is heard only if you deliberately route it to the audible path.

KICK TRIGGER→SIDECHAIN INPUT→BASS DUCK

Use for: kick/bass separation, rhythmic pad movement and intentional pumping.

05 / Instrument bus

Route related tracks to a shared bus for broad tone, glue and group automation.

KICKSNAREHATS→DRUM BUS→MASTER

Use for: drums, guitars, backing vocals, synth layers and orchestral sections.

06 / Mid-side thinking

Center holds stable mono anchors; sides add width and ambience. This is a mix perspective, not a requirement to process every track.

MID / CENTER+SIDE / WIDTH→STEREO OUT

Use for: checking stereo ambience, upper-harmonic width and mono compatibility.

FL Studio routing note: Use the Mixer to route source inserts to buses and effect returns. For sidechain compression, create a sidechain-only send from the trigger track to the target insert, then select that input in Fruity Limiter's compressor section. Exact steps can vary with project routing and FL Studio version.

MIX TROUBLESHOOTER

Start with diagnosis, then choose the smallest useful correction.
Diagnostic rule: Before adding another plugin, bypass the chain, level-match, mute competing tracks and identify whether the problem is source, arrangement, performance, routing or processing.
